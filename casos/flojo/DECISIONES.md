# Decisiones

Definimos que el agente iba a clasificar tickets por prioridad y área.
Escribimos el system prompt, lo probamos con un par de tickets de
ejemplo y anduvo bien de entrada. Ajustamos un poco la redacción del
prompt para que la salida fuera más corta y quedó funcionando. No tuvimos
mayores problemas durante el desarrollo, todo salió como lo planeamos
desde el principio.

Elegimos `claude-sonnet-5` porque es el modelo recomendado para este tipo
de tareas y nos pareció suficiente para el volumen que vamos a manejar.
